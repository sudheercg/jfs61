Control flow: 


Control flos statements are statements in java which 
control the order in which the instsructions are 
executed in a program based on conditions.


By default, statements are executed top to bottom.

Control flow allows us to change this normal  
execution order. 

Control flow statements can be categorized into: 

1. Selection(Decision-making) statements:
    if
    if-else
    else-if
    switch..case
    
 2. Iteration(Looping) statements:
     for
     while
     do-while
     enhanced - for
     
 3. Jump(Branching) statements:
     continue
     break
     return

 if-else-if ladder:
 ==================
 if- else -if ladder is a control flow statement
 used to check multiple conditions sequentially
 and executes the block with the first condition
 which is evaluated as true;
 
 if(condition1){
    //executes if condition is true
 }
 else if(condition2){
   //executes if condition2 is true
 }
 else if(condition3){
    //executes if  condition3 is true
  }
  else{
  // Executes if all conditions above are false
  // executes if none of the above conditions are true
  }

 switch case:
 ------------
 
 switch statement is a decision making control flow statement which allows us to 
 execute one block of code from multiple alternatives based on the 
 value of an expression. 
 
 We can write code in simple way using switch case. 
 
 It is mainly used to compare a single expression with 
 multiple fixed values, instead of using multiple if-else-if ladder. 
 
 Syntax:
 
 switch(expression){
 
   case value1:
     //statements to execute
     break;
  
  case value2:
    //statemens to execute
    break;
  
  case value3:
    //statement to execute
    break;
    
  default: 
   //statements if none of the above case matches
   }
 
 
 
 
 
 
 }
